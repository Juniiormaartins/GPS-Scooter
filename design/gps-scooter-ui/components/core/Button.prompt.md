The screen's committing action — one per screen, full width, at the bottom of a sheet or form.

```jsx
<Button variant="go" size="lg" icon={<Icon name="navigation" size={22} />}>Iniciar Navegação</Button>
```

Variants: `go` (green — start/confirm a ride), `primary` (blue — everything else), `secondary` (raised card fill), `quiet` (tinted blue chip-style, e.g. "+ Adicionar"), `ghost`, `destructive` ("Sair da Conta"). Press state is scale 0.97 + 12% dim, never a color change.
